# 平行世界 · Parallel World Labs

平行世界在建设一套面向真实团体工作的 AI 运营体系。我们把真实团体运营的业务工作拆成有明确目标、权限和验收标准的数字岗位，让 AI Agent 在授权下与真实人员平行执行，并留下可核对的业务记录。

## 项目方向

首个运营单元（POD）正在城建设。我们从具体业务流程入手，验证 AI 平行工作。配套的 AIOS 用于管理 Agent、工具、知识和项目。

## 长期展望

我们希望把首个 POD 的实践发展成可复用的方法，逐步建设面向不同产业或地点的运营单元。各单元有明确的业务范围、负责人和权限，在获得授权后可以交接任务、开展协作。

后续我们会在这个 GitHub 组织陆续发布多个项目，并随项目发布提供相应的文档和使用入口。
