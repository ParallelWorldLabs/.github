# 平行世界 · Parallel World Labs

我们在建设一套面向真实企业工作的 AI 运营体系。把资料整理、询盘跟进、报价准备和订单核对等工作拆成有明确目标、权限和验收标准的数字岗位，让 AI Agent 在业务负责人的授权下执行。

首个运营单元（POD）在宁波汽车城建设中，优先面向宁波外贸和跨境电商产业链。配套的 AIOS 用于管理 Agent、工具、知识和项目。

## 公开项目

- [平行世界 Odoo 工作台](https://github.com/ParallelWorldLabs/PW-Plugins-Odoo) 为 DeepSeek Harness 提供 Odoo 只读工作台，可在 Agent 对话旁查看 CRM、销售、采购和库存。安装步骤和使用说明见项目仓库。

## 业务合作

[BlueWMS](https://github.com/bluewms/bluewms) 是由宁波宝蓝物流科技有限公司维护的仓储管理系统。平行世界与 BlueWMS 在软件推广和业务运营上开展协作。
